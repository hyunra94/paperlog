# Paper Log v93

득템 메모를 보스별로 분배하지 않고, 캐릭터별 `득템` 섹션에서만 조회/저장합니다.

- 화면 구조: 1인 파티 / 2인 파티 / 기타 인원 / 득템
- `물욕템 or 메모`는 캐릭터별 보스 기록의 득템 메모로만 읽고 씁니다.
- 보스명을 클릭하면 `보스명: 입력내용` 형식으로 캐릭터의 득템 메모에 추가됩니다.
- 득템 섹션 줄을 클릭하면 캐릭터의 전체 득템 메모를 수정할 수 있습니다.
- 보스 개별 금액과 캐릭터 결정석 합계에는 득템 금액을 더하지 않습니다.
- 1인/2인/기타 파티 제목 옆 금액 제거, 전체 체크/해제 버튼 제거 유지.
